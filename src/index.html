About Project Pastro

Project Pastro is a personal cookbook accessible from anywhere on the web. Pastro aims to be mobile-first and user focused by creating a scalable platform for near-instant recipe additions and modifications, with features to appease power users while providing an interface for even less-savvy tech users.
